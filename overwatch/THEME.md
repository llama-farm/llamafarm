# Theme Override — READ THIS

Use dark navy palette instead of pure black/gray. Think military command center — not terminal.

## Colors
- Background (main): `#0d1b2a` (deep navy)
- Background (cards/panels): `#1b2838` (slightly lighter navy)
- Background (elevated/modals): `#243447` (medium navy)
- Top bar / fleet strip: `#152232` (dark navy)
- Text primary: `#e0e6ed` (soft white, not pure white)
- Text secondary: `#8899aa` (muted blue-gray)
- Borders: `#2a3a4a` (subtle navy border)
- Accent/interactive: `#4a9eff` (bright blue)
- Status green: `#22c55e`
- Status amber: `#f59e0b`  
- Status red: `#ef4444`
- Kill button: `#dc2626` background, stays red

## Tailwind config
Update tailwind.config.js colors to use these navy values. Replace all bg-gray-900, bg-gray-800, bg-black, etc with the navy equivalents.
