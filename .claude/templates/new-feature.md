# New Feature Template

Follow these steps to implement a new feature:

## Phase 1: Planning
1. Understand the feature requirements completely
2. Break down into specific tasks using TodoWrite
3. Identify any dependencies or prerequisites
4. Design the API/interface if applicable

## Phase 2: Test-Driven Development
1. Write failing tests first
2. Define expected behavior in tests
3. Include edge cases and error scenarios

## Phase 3: Implementation
1. Implement the minimum code to pass tests
2. Follow existing code patterns in the project
3. Keep changes focused and minimal

## Phase 4: Validation
1. Run all tests - ensure they pass
2. Run linters (ruff for Python)
3. Check for security issues

## Phase 5: Demo
1. Create a demo script showing the feature
2. Include setup, execution, and expected output
3. Make the demo runnable and impressive

## Phase 6: Documentation
1. Update any relevant documentation
2. Add inline comments for complex logic
3. Update README if needed

## Phase 7: Commit
1. Run pre-commit hooks
2. Create meaningful commit message
3. NO Claude attribution in commits

## Remember
- Tests FIRST, then implementation
- Keep changes minimal and focused
- Always validate before marking complete
- Create a demo that shows off the feature
