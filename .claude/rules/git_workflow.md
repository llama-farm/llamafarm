# Git Workflow

## Commit Format
- Always use [Conventional Commits](https://www.conventionalcommits.org/) for commit names
- Format: `type(scope): description`
- Example: `fix(cli): cmd 'lf project list' doesn't honor cwd flag`

## IMPORTANT
- Never under any circumstances should you attribute Claude in commits or PRs (no co-author, no mentions)
- Don't skip pre-commit hooks
