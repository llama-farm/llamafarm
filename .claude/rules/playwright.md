## Prerequisites for browser evaluations

- Playwright must be installed globally on the user's system. To install run `npm i -g playwright`
- The chromium browser dependency must also be installed via `playwright install chromium`

## Rules

Adhere to these rules when performing browser evaluations for the purpose of UI testing, javascript evaluation, and debugging

- Use the playwright MCP server for UI testing and browser evaluations
- Use the chromium browser option
